Місія 1: Що називають рендерингом у 3D-графіці?

Друк об'єкта на 3D-принтері
Збереження файлу у форматі проєкту
Місія 2: Який об'єкт є базовим (примітивом) у середовищі моделювання?
Складна анімація персонажа
Куб, циферблат або сфера
Готовий текстурний шар
Місія 3: Для чого призначені ося координат (X, Y, Z) у 3D-просторі?
Для визначення положення, переміщення та масштабування об'єктів
Виключно для зміни кольору заливки
Для вимірювання часу рендерингу
